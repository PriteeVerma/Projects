## 📊 Sales Data Analysis

### About the Project

This is a small sales data analysis project created using Python and NumPy.

The main aim of this project is to understand monthly sales data for three different regions and find some useful insights from it.

### What I Worked On

- Created a sales dataset using NumPy
- Checked the shape and dimensions of the data
- Calculated total sales
- Compared sales across different regions
- Analyzed monthly sales performance
- Used Boolean indexing to filter sales values above ₹4,000

### Tools Used

- Python
- NumPy
- Jupyter Notebook
- Google Colab

### What I Learned

Through this project, I practiced working with NumPy arrays, aggregation using different axes, and filtering data using Boolean indexing.

It also helped me understand how basic data analysis techniques can be used to look at sales performance and find useful patterns in data.
